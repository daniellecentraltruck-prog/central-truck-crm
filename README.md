# Central Truck CRM
CRM comercial conectado ao Supabase.

## Variaveis de ambiente
Crie `.env` a partir de `.env.example` e informe a chave publicavel do Supabase.

```
VITE_SUPABASE_URL=https://jlvnitdigdxtroczsowd.supabase.co
VITE_SUPABASE_PUBLISHABLE_KEY=sb_publishable_...
```

Nunca coloque chaves `sb_secret_` ou `service_role` no frontend.
